# Bug Reports

This repository contains professional bug report examples created during QA practice and testing exercises.

---

# 🧪 Contents

Each report may include:

* Bug description
* Environment details
* Steps to reproduce
* Expected result
* Actual result
* Severity
* Screenshots

---

# 🎯 Objective

Practice professional QA documentation and improve bug reporting skills.
