# Bug Reports

Collection of manual QA findings and visual/UI inconsistencies discovered during exploratory testing on real websites.

This repository contains documented bug reports including:
- Reproduction steps
- Expected vs actual behavior
- Severity assessment
- Screenshots and GIF evidence
- UI and rendering issues

## Included Cases

### Slider Instability Bug
UI issue caused by rapid image navigation in a property gallery slider.

### Broken Thumbnail Rendering
Broken or unloaded property thumbnail displayed in the related properties sidebar.
